# Problem Solving Techniques (PST) Lab
### 1st Semester – Bachelor of Computer Applications (BCA)

Welcome to the **Problem Solving Techniques Lab (PST)** repository. This repository contains C programming lab exercises for 1st Semester BCA students, covering **Part A and Part B** practical programs.

The purpose of this repository is to help students understand programming fundamentals, develop logical thinking, and gain practical experience in writing, compiling, and executing C programs.

---

## 📚 About the Lab

The Problem Solving Techniques Lab introduces students to fundamental concepts of programming using the C language. The exercises help students develop problem-solving skills and understand how programming concepts are applied to solve computational problems.

The repository serves as a reference for lab practice, revision, and practical examination preparation.

---

## 📂 Repository Contents

- **Part A** – Lab exercises and programming practice.
- **Part B** – Programming problems based on the prescribed practical list.
- **C Source Files** – Programs written in C.
- **Program Outputs** – Sample outputs wherever provided.

---

## 💻 Technologies Used

- **Programming Language:** C
- **Compiler:** GCC
- **Environment:** Windows / Linux
- **IDE:** Code::Blocks, Dev-C++, Visual Studio Code, or any C-compatible IDE

---

## ⚙️ How to Compile and Run

### 1. Compile a C program

```bash
gcc filename.c -o program
```

### 2. Run the program

**Windows:**
```bash
program.exe
```

**Linux:**
```bash
./program
```

For programs that use mathematical functions from `math.h`:

```bash
gcc filename.c -o program -lm
```

## 📖 Concepts Covered

Depending on the exercise, the lab programs cover:

- Basic input and output
- Variables, constants and data types
- Operators and expressions
- Decision-making statements
- If-else and switch-case
- Looping statements
- Number-based problems
- Arrays and matrices
- String manipulation
- Functions
- Pointers
- Structures and unions
- Pattern printing
- Basic logic building and problem-solving techniques

---

## 🎯 Learning Objectives

By practicing these programs, students will be able to:

- Understand the fundamentals of C programming.
- Develop logical and computational thinking.
- Write, compile, debug, and execute C programs.
- Apply conditional and looping constructs to solve problems.
- Work with arrays, strings, functions, and pointers.
- Understand user-defined data types such as structures and unions.
- Improve their confidence in practical lab examinations.

---

## 🧪 Lab Practice

Students are encouraged to:

1. Read and understand the problem statement.
2. Analyze the logic before writing the code.
3. Write the program independently.
4. Compile and execute the program.
5. Test the program with different inputs.
6. Understand the output and be prepared to explain the logic during viva.
